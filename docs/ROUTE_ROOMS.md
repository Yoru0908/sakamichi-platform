# 巡礼ルートの共有と共同編集

2026-10-11 実装（未デプロイ）。ブランチ `feat/route-share*`。

## できること
- **画像で共有**: 略図（座標を投影、底図なし）+ A/B/C… の番号付きリストの PNG。Canvas 描画、依存なし。
- **リンクをコピー**: `?route=<base64url>`。地点キーと移動方法だけを運ぶ。開くと確認の上で現在のルートを置き換える。
- **共同編集**: `?room=<id>`。同じルームを開いた人が同じルートを編集する（5 秒ポーリング）。

## 仕組み
- API: `/api/route-rooms`（POST 作成 / GET 取得 / PUT 更新 / GET `/_` 利用可否）。
- 保存: D1 `route_rooms`（id, title, mode, keys JSON, version, 時刻）。90 日更新が無ければ作成時に遅延削除。作成は 1 時間 300 件まで。
- 認可: なし。推測不能な 10 文字 id を知っている人が読み書きできる（リンク = 編集権）。現在地・進捗は保存しない。
- 競合: PUT は `baseVersion` の楽観ロック。409 のときクライアントが自分の差分（追加/削除/並べ替え）を最新に載せ直して一度だけ再送。
- ローカルのルートが引き続き作業コピー。ルーム終了後も端末に残る。参加時は先にサーバー状態を取り込み、以降にだけ送信する（古いローカルがルームを上書きしない）。
- バックエンドが無い/D1 未接続 → API は 503、画面は「共同編集」を出さない。
