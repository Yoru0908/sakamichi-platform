# Miguri 日期结构修复（2026-09-13）

## 根因

日向坂18单增加 2026-11-29，仅森本茉莉参加，只有4部，第4部15:30开始；常规日期第4部16:00开始。旧解析器把两份时刻表铺平成一份，产生重复部次。旧同步分批提交删除/插入，后续插入失败时已提交的删除无法回滚，导致当前活动的部次/成员表为空。快照并没有丢失，但矩阵缺少可靠的日期与分母。

## 修复

- `dateSchedules` 保存日期专属部次与限定成员；额外时刻表或参与条件不明确时拒绝同步，不猜测。
- 入库前验证重复部次、非法时间、重复日期 override、未知限定成员。
- `miguri-structure.ts` 用 `json_each` 批量插入；活动更新、归档、删除、替换放在一个 D1 transactional batch，任一步失败全部回滚，失败不发布缓存。
- 移除依据成员/元数据差异生成完售格的旧逻辑；只有实际 soldout import 才能产生完售观测。
- 详情返回 `slotsByDate` / `memberSlotKeys`；矩阵按每个日期实际列数显示，非参与成员为灰色「— / 未安排」，不是未售。
- 删除管理页顶部两条重复推广链接，保留 Miguri 下拉、手机菜单、活动总览和页脚入口。
