# Sakumimi 旧期资源与历史成员筛选修复（2026-09-05）

## 根因

AList 索引含606期。第1–570期的 `cover_url` 与 `audio_url` 仍使用已无法解析的 `alist.sakamichi-tools.cn`；571–606期使用 `alist.46log.com`。抽查 EP001、EP550、EP569、EP570，保持路径仅更换域名后均返回200、有效JPEG，文件没有丢失。

## 修复范围

- `sakumimi-archive-data.ts` 在索引进入前端状态时统一规范封面、音频和源图URL，仅迁移准确匹配的旧AList主机，保留路径与查询参数，不改其他域名。
- 图片按归档封面、原始图片、期号占位依次降级；不再显示破图。
- 成员筛选保留樱坂现役期别，结合樱耳索引中的实际出演标签补充历史成员，当前共44名（32现役、12历史成员）。没有头像仍可筛选；不添加其他团体名册。
- 历史组使用「卒業・過去の出演メンバー」，避免仅凭现役名册缺失就错误断言毕业状态。按钮显示节目数量；统一去除姓名空格，避免筛选无法匹配标签。

## 运维边界

这是46log前端对历史索引的兼容修复，**未改写 Homeserver 上原始索引**。本轮LAN和Tailscale SSH均无法连接；后续可在恢复连接后另行原子迁移历史索引URL。自动上传脚本目前已写新域名，新期无需调整。

部署使用当前生产提交的隔离worktree构建，只加入本次radio修复，避免将主工作区未提交的日程与Worker修改带入发布。不需要重启radio-backend或任何PM2服务；不修改媒体文件、账户数据或服务器配置。
